# Library Management System

A Java-based Library Management System developed as an academic project.

## Features

- User registration and login
- User dashboard
- Book management
- Book borrowing requests
- Borrowing history
- Librarian dashboard
- Librarian history
- Admin dashboard
- User management
- Record management

## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL

## Project Structure

The application contains separate modules for:

- Admin
- Librarian
- User
- Book Management
- Database Connectivity

## Note

This project was originally developed and executed using NetBeans.
The repository contains the original Java source code of the project.
